# ADR-0007: Seam-и тестованості — JOBRADAR_HOME і інжектований годинник

Дата: 2026-08-19
Статус: ухвалено

## Контекст
Система стає портфоліо-репо, яке має демонструвати тестованість, і паралельно
дістає окремий E2E-набір (`jobradar-e2e/`, Playwright/Node). Стара кодова база
тестувалась монкіпатчингом констант модуля: `jobradar.DB_PATH = tmp`,
`profile.PROFILE_JSON = tmp`, підміна `datetime.now()` була неможлива взагалі.
Це тендітно (тест знає внутрішні імена), не працює між процесами (E2E-сервер —
окремий процес) і змушувало копіювати дерево на воркер. Користувач сформулював
п'ять вимог до тестованості; дві з них — фундаментальні seam-и рівня рантайму.

## Рішення
- **`jobradar/paths.py` — єдине джерело шляхів (вимога #1).** Змінні дані
  (config, jobs.db, profile.json/.md, лог, .lock) резолвляться від `home()`:
  `JOBRADAR_HOME` (env — для окремого процесу E2E), інакше `use_home()`
  (перекрив у процесі — pytest), інакше корінь проєкту (як за ADR-0005).
  Жодних шляхових констант у модулях; усі питають `paths.*` на кожен виклик.
- **`jobradar/clock.py` — одна точка «зараз» (вимога #2).** `now()` (UTC-aware)
  + `freeze()/unfreeze()`. recency-фільтр, календар і TTL дедупу ходять через
  `clock.now()`. Тест заморожує час — плавучі перевірки «за 24 год» / «поточний
  місяць» стають детермінованими.
- `conftest` має autouse-фікстуру, що скидає HOME і годинник між тестами.

Решта вимог лягає на пізніші етапи: підмінний скорер (#3) і джерело (#4) —
на розборі ядра (`scoring`, `collectors`); стабільні `data-testid` (#5) — на
розборі презентації.

## Відкинуті альтернативи
- **Лишити монкіпатч констант.** Працює в процесі, але не між процесами (E2E),
  і тест чіпляється за внутрішні імена. Саме те, що вимога #1 просить прибрати.
- **Module `__getattr__` для динамічного `DB_PATH`.** Зберіг би сумісність без
  правок тестів, але магічно й не покриває E2E-процес; env-механізм явніший.
- **Бібліотека на кшталт `freezegun` для часу.** Зайва runtime-залежність проти
  ADR-0004; 12-рядковий власний `clock` робить рівно потрібне.

## Наслідки
+ Ізоляція тесту — один рядок (`paths.use_home(tmp)` / `clock.freeze(dt)`),
  без копіювання дерева й без знання внутрішніх констант.
+ E2E піднімає сервер як `JOBRADAR_HOME=/tmp/x python -m jobradar serve` і дістає
  повну ізоляцію даних — те, чого монкіпатч у процесі дати не міг.
+ Перевірено наживо: БД створюється в HOME, робоча не чіпається; заморожений
  годинник керує `now_iso()`.
− `paths.*`/`clock.now()` — виклик функції замість константи (мікро-накладні,
  не в гарячих циклах); свідомий обмін на тестованість.
− `use_home()`/`freeze()` — процесний глобальний стан; безпечний лише завдяки
  дисципліні скидання (autouse-фікстура). Документовано як тест-seam.
