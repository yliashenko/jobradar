# ADR — Architecture Decision Records

Кожен запис — одне ухвалене рішення з контекстом і відкинутими
альтернативами. Народжуються з грилінг-сесій та інженерних розвилок.

Правила:
- Нумерація наскрізна: 0001, 0002, …
- ADR не редагується заднім числом — застаріле рішення отримує статус
  «замінено ADR-XXXX», і пишеться новий запис.
- Рішення, що вже зафіксовані у PRODUCT.md / CLAUDE.md, НЕ дублюються
  сюди механічно; ADR з'являється, коли рішення перевідкрито, оскаржено
  або ухвалено вперше.
