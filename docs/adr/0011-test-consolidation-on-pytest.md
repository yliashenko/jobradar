# ADR-0011: Консолідація тестів на pytest; пенсіонування selftest.py

Дата: 2026-08-20
Статус: ухвалено (завершує міграцію, розпочату ADR-0004)

## Контекст
ADR-0004 завів pytest-шар паралельно з саморобним `selftest.py` на «подвійний
прогін» під час міграції. Два тест-фреймворки поруч — анти-сигнал для портфоліо
і зайвий гейт. Після розбору ядра (ADR-0009) pytest покриває майже все;
лишалось перенести унікальне покриття selftest.

## Рішення
- Унікальне покриття selftest мігровано в організовані pytest-модулі:
  `test_collectors` (парсери email-алертів Djinni/LinkedIn), `test_notify`,
  `test_runner` (лок / single-flight / звільнення локу при падінні / індикатор),
  `test_text` (санітайзер, дати), `test_db` (міграція старої БД, журнал).
- `selftest.py` видалено; прибрано з CI, Makefile і ruff-exclude.
- Єдиний гейт: `make check` = ruff + mypy + css-check + pytest під coverage.

## Відкинуті альтернативи
- **Лишити selftest як «димовий» шар.** Дублює pytest і тримає окремий раннер;
  міграція завершена, тримати два фреймворки нема причини.

## Наслідки
+ Один тест-фреймворк, тести по концернах; 185 тестів, coverage-звіт у CI.
+ Гейт простіший і однорідний.
− Кілька render-smoke-перевірок selftest (layout, runbox) поглинулись
  сторінковими тестами `test_profile`; за потреби доростають окремо.
