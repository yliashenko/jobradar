# ADR-0003: Особистий інструмент спершу; продуктовий трек заморожено

Дата: 2026-08-14
Статус: ухвалено

## Контекст
Грилінг-сесія по продуктовому плану дала три результати, що мають один
корінь. Питання 1: гейт цінності Phase 1 виявився контамінованим (ADR-0001
переписав його на блайнд-тест, який потребує чужих профілів). Питання 2:
ICP названий персонами, але «два блайнд-читачі цього місяця» лишилось без
відповіді. Питання 3: теза продукту захиталась між «дзеркалом» і
«структурованим фідом» — і вибір вимагає даних про те, що реально цінне.
Спільний корінь: відповіді на всі три питання потребують працюючого
інструмента і реальних даних, яких немає. Продовження продуктового
планування в цій точці — вигадування. Паралельно продуктова робота
конкурує за час із пошуком роботи — метою, заради якої інструмент існує.

## Рішення
Фокус — реально робочий інструмент особисто для засновника.
- Phase 0–1 з PRODUCT.md чинні як особистий беклог (NAS, enrichment,
  таксономія, gaps, картка-чекліст, компенсаційне v0).
- Phase 2–4, монетизація, ICP, блайнд-тести, вибір обіцянки №1 —
  заморожені й не обговорюються до свідомого розморожування.
- Питання 3 (дзеркало vs фід) знято з порядку денного: для одного
  користувача обидва views співіснують без обіцянки №1.
- PRODUCT.md не видаляється — він капітал: карта джерел, зарплатні проби,
  стрес-тест, стек. Отримує банер «заморожено».

Умови повернення до продуктового треку (усі — сигнали, не автоматика;
розморожування — окреме свідоме рішення):
1. радар ≥4 тижнів у бойовому режимі на NAS;
2. пошук роботи не в активній критичній фазі;
3. зовнішня тяга — хтось реальний просить доступ або звіт.
Перший кандидат при розморожуванні — трек «особистий інструмент +
публічний тижневий звіт» (PRODUCT.md §15: ~20% зусиль, ~60%
дистрибуційної цінності), не повний SaaS.

## Відкинуті альтернативи
- Продовжити продуктове планування: питання 1–3 без даних не
  закриваються; план деградує у фантазії.
- Поховати продуктовий трек повністю: дослідження не протухає швидко,
  а data-first означає, що особиста робота колектора все одно нарощує
  той самий актив даних.
- Стрибнути одразу в «звіт-трек»: це теж дистрибуційна робота, що
  конкурує з пошуком; відкладено як перший кандидат на потім.

## Наслідки
+ Фокус і зняте навантаження рішень: наступний крок — Етап A
  двоетапного промпта, без продуктових питань.
+ Час повертається справжньому вузькому місцю пошуку (портфоліо,
  інтерв'ю).
+ Кожен тиждень особистої роботи все одно накопичує дані для можливого
  майбутнього продукту — задарма.
− Чесний ризик: «потім» може не настати ніколи. Прийнято свідомо.
